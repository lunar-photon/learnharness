# PYQ — past-year questions and level-setting material

Put the material your tests should match here, one folder per exam:

```
PYQ/
  CGL/            ← bundled on this machine: MPSC Combined Group B & C (Maharashtra "CGL")
    *.pdf         question papers and their answer keys (first/final keys)
    urls.txt      where each file was downloaded from
    RESOURCES.md  notes on the exam: pattern, syllabus, sources
  <Your exam>/    ← add your own: papers, answer keys, sample tests, notes on the pattern
```

An exam-prep session reads its exam's folder before planning. It extracts each paper's questions, pairs them
with the matching answer key, and tags them by topic and difficulty. Generated quizzes and mock tests are then
pitched **at or above the level of this material**, and a share of the real questions is held back, unseen, to
measure your readiness.

Anything you add counts: scanned or text PDFs (scans are read page by page by a vision-capable model), answer
keys, sample papers, a text file describing the pattern (sections, question types, duration, marking). Name
files so a paper and its key are recognisably paired (same year and paper number).

Files in this folder stay on your machine. Only this README is committed (see `.gitignore`).
