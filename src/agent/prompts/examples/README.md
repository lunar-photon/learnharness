# Example library

Worked examples of how this learner wants ideas framed: a generic answer, the preferred construction, and the
teaching lesson that separates them. The teacher's `example` tool lists every numbered `NN-slug.md` file here
(title + its `Lesson:` line) and returns one in full on request. Examples demonstrate a reasoning process; they are
not templates to reproduce.

File shape: `# Title`, a one-line `Lesson:`, then `## Generic answer` (optional), `## Preferred construction`,
`## Teaching lesson`, and `## Accuracy constraint` (optional).

Figures an example refers to live in `figures/`, named after the example (`05-…png`); the example's text describes the figure, since the `example` tool returns text only.
